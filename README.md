# Norcal Dragonboat Race Results
This project is a frontend dashboard that reads race data from a Google Sheets source and displays it in a structured, user-friendly interface. It was built to improve accessibility of race results by replacing manual spreadsheet viewing with a clean, real-time visual display.

## [Link to site](https://sfdb-app.vercel.app)

Built With:
- NextJS
- React
- Javascript
- Supabase
- Vercel
